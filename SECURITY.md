# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue: use **Report a vulnerability** on this repository's [Security tab](https://github.com/natezimm/rabbit-ears/security/advisories/new). Include what you found, how to reproduce it and what it lets someone do. You should hear back within a week.

You are welcome to test the demo at [rabbitears.nathanzimmerman.com](https://rabbitears.nathanzimmerman.com) gently; it is rate limited and each visitor gets their own room. Please do not run load tests or try to reach the server itself.

At home the box has no accounts or logins by design, so anyone on the home network can use the remote; that alone is not a vulnerability. Reaching the box's files beyond its media folder, getting the demo to read or serve anything other than its own media, or reaching another visitor's room on the demo is.

## Supported versions

Only what is on `main` is supported.
